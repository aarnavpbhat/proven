        Summary

        Each close is generated with a known cause and, for defect families, exactly one injected error. Seen phrasing uses wording the lexicon covers; held-out phrasing describes the same causes in words it has never seen; paraphrase rewrites the sentences themselves. The oracle extractor hands the checker the generator's own claims, so it shows the ceiling a perfect extractor would reach. Only offline extractors run here; benchmarking a model extractor is a command-line job (python -m proven benchmark --extractor …) so nothing in this tab can spend money. The generator, lexicon and checker share an author, so these numbers are a consistency check, not evidence of accuracy on real commentary.
